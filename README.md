import them. One file for the whole catalogue, and one per topic if you only want
a slice.

## How to use them

Download a file and import it. In most readers the menu item is Import OPML or
Add subscriptions:

- **NetNewsWire** File, Import Subscriptions
- **Reeder** Settings, Subscriptions, Import
- **Feedly, Inoreader, The Old Reader, Miniflux, FreshRSS, Newsblur** all accept OPML

Nothing here phones home. An OPML file is a list of feed URLs, so importing one
subscribes you directly to the publishers, with no service in between.

## How the sources were chosen

Every source was scored on eight dimensions: editorial quality, ad restraint,
reach, signal-to-noise, access, cadence, aesthetic and independence. The ad and
performance numbers are measured rather than judged, by loading each site in a
real browser with the cookie banner accepted, then counting ad entities,
third-party domains and layout shift.

The weights and the full method are published, including what each dimension
means and how ties are broken: <https://feeds.bar/signal-500/method>

Per-source pages show the measurements behind each score:
<https://feeds.bar/signal-500/>

A companion study applies the same measurements to 890 news sites:
<https://feeds.bar/reading-the-news-2026/>

## Scope and honesty about bias

This is a curated list, not a census. It leans English-language, and it favours
sources that load quickly and carry few ads, because that is what the scoring
rewards. Some well-known publications rank low for exactly that reason. The
method page states the weights, so you can disagree with the ranking on the
evidence rather than on taste.

Corrections are welcome: open an issue, or email <hello@feeds.bar>.
